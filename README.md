# Om Mig - Daniell Remmel

Detta är min personliga webbplats byggd som ett praktiskt projektarbete i kursen Bootcamp på Chas Academy. Sidan presenterar vem jag är, mina intressen, mina projekt och mina färdigheter inom frontend och UX-engineering.

Vad var svårast, och hur löste du det?

under tiden när jag förbättrade min kod så krockade jag med två små svårigheter så som att lägga till bilderna och h3 rubrik som vägrade ändras inte när jag skrev i min css. Lösningen för h3 var att lägga till en class och döpt till text vilket underlättade och ändrade till formaten som jag ville i början. 

den andra svårighet jag upptäkte var själva bilden som inte visade sig upp, även fast koden skrevs rätt så var främsta anledning att bild format var sparad utanför mappen vilket löste sig genom att sätta till samma mappen. 

enligt mig de mest svåraste var skriva java script kod speciellt för att testa mig själv skriva om koden så de fungerar samma sätt som innan

Vad kom fram i kodgranskningen, och vad valde du att åtgärda? Vad valde du bort, och varför?

under kodgranskningen upptäckte jag ett par saker som behövdes förbättra för att uppfylla hygienkraven. 
Exempelvis när jag upptäckte att koden kunde vara mer semantisk genom att åtgärda div taggar eftersom vi gillar inte divsoppa i koden, istället så ersätt med article samt sökte google och använt details tagg.
Annan exempel är med javascript innan så hade jag längst ner under body men efter undervisning med utbildare så flyttade direkt till head som man ska eftersom filen börjar laddas ner direkt, laddar parallellt med HTML. samt lagt till defer för att förhindra att koden kraschar.

Vad skulle du göra härnäst om du hade mer tid?

Efter att ha sett Olivers och Hampus webbplatser blev jag väldigt inspirerad av hur de arbetade med interaktivitet och visuella effekter. Om jag hade haft mer tid skulle jag vilja:

Mindre animationer och mikrointeraktioner: Bygga snygga CSS-animationer där objekt rör sig responsivt och mjukt när användaren klickar på dem.

 Skapa en interaktiv tidslinje över min utbildning och mina projekt för att göra strukturen ännu mer visuellt tilltalande.

Design polish: Polera helhetsdesignen, finjustera typografi, färgval och spacing för en ännu mer stilren och modern.
